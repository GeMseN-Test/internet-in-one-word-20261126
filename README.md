Entry for the [The Internet in One Word](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b) competition on make.fun.

This entry submits the single word **Ballyhoo** — loud, sensational commotion over next to nothing, which sums up the whole internet in one beat. Running `python3 main.py` writes `Ballyhoo` to `/output/entry.txt`.
